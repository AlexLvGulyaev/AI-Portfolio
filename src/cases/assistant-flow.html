n8n OpenAI Telegram CRM
GitHub Demo

Компания обрабатывала большое количество входящих заявок от клиентов через различные каналы: сайт, Telegram, телефон.

Основные проблемы:

  • Задержки в обработке заявок
  • Ошибки в маршрутизации
  • Неравномерная нагрузка на сотрудников
  • Отсутствие единой системы учёта

Разработан AI-ассистент на базе n8n с интеграцией OpenAI и Telegram.

Возможности системы:

  • Приём заявок из нескольких каналов
  • Классификация обращений по категориям
  • Определение приоритета и ответственного
  • Автоответы на типовые вопросы
  • Интеграция с CRM
  • Уведомления ответственным
