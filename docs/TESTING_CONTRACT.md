```bash
cd backend && .venv/bin/python -m pytest tests/ -q
```

| Параметр | Значение |
|----------|----------|

| Текущий результат | 242 passed, 3 skipped (на хосте вне compose) |
| Smoke-тесты БД | 2 теста `test_services_smoke.py` требуют живого PostgreSQL по адресу compose-сети — в контуре хоста не проходят; в контуре развёрнутой системы проходят штатно |

**Критерий приёмки изменений:** зелёный полный набор перед коммитом; красные smoke-тесты БД — ожидаемы только вне compose-окружения.

## 🎯 3. Eval-прогоны

Качество ассистента проверяется прогонами через живой пайплайн (`POST /chat`), не моками.

### Наборы

| Набор | Состав | Назначение |
|-------|--------|------------|
| **Публичный eval-сет** | 24 теста, классы A–M (файл `backend/tests/ai_portfolio_eval_set.json`) | Регрессия качества: перечисление кейсов, факты о проектах, диалоговая память, отказы, честность |
| **Полный regression set** | 168 тестов, классы A–M | Контрольная кампания при изменениях промпта/retrieval/KB |
| **Класс X** | 8 «грязных» формулировок (опечатки, транслит, размытые фразы) | Понимание фразы; добавляется к regression set |

### Принятые результаты (28.08.2026, принятые владельцем)

| Метрика | Значение | Критерий |
|---------|----------|----------|
| Корректность (regression) | 159/168 = **94,6%** | ≥90% ✅ |
| Класс C (факты о проектах) | 68/77 = 88,3% (уровень зафиксирован) | — |
| Latency p95 (cache-miss) | **4956 мс** | <5000 мс ✅ |

### Правила прогона (важные)

- Кеш ответов сбрасывается (с бэкапом) перед каждым измерительным прогоном — прогон на прогретом кеше меряет кеш, а не поведение.
- Изолированный `visitor_id` на запуск: eval-трафик не смешивается с реальными посетителями.
- Сессия диалоговой группы якорится: первый запрос группы без `session_id`, последующие — с `session_id` из ответа сервера (сервер валидирует переданный id).
- Класс C стохастически колеблется между прогонами (наблюдаемый диапазон 88,3–90,9%); повторные полные прогоны — только по согласованию с владельцем.

Методика, состав классов, раннер и разборы дефектов — [`docs/AI_EVAL_REPORT.md`](AI_EVAL_REPORT.md) §6–§7.
