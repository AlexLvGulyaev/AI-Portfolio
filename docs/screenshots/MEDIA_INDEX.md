# 📷 MEDIA_INDEX — AI Portfolio

**Назначение:** каталог медиаматериалов платформы AI Portfolio. Схема нейминга, состав, матрица использования. Кейс-материалы (диаграммы, скриншоты лендингов) живут в `src/assets/cases/` и не входят в этот индекс.

---

## 🏷️ 1. Схема нейминга

Формат: `AIP_<категория>_<описание>.png`

| Категория | Назначение |
|-----------|------------|
| `ui` | Скриншоты пользовательского интерфейса (сайт, чат-виджет, Admin Console) |
| `arch` | Архитектурные схемы (архитектурные схемы — в Mermaid внутри Markdown, PNG — только для сложных диаграмм) |
| `flow` | Диаграммы процессов |

Пример: `AIP_ui_chat_sources.png`.

## 🧭 3. Принцип выбора

Каждое изображение объясняет конкретную мысль документа; скриншоты вставляются по назначению, а не «потому что есть». Соответствие изображения подписи проверяет человек с доступом к файлу — визуальная валидация изображений выполняется владельцем.
