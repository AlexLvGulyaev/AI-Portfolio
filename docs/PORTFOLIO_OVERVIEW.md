# Обзор портфеля AI Portfolio

Карта реализованных проектов: для каждого направления — что уже решено и где смотреть. Официальный состав портфеля — 13 проектов; эта страница объясняет логику группировки (какой класс задач каким проектом закрыт) и даёт прямые ссылки на страницы кейсов.

Коротко о направлениях:

- **RAG-ассистенты и базы знаний** — доступ к документации и обращениям через диалоговый поиск;
- **Автоматизация работы с отзывами** — LLM-генерация и обработка под контролем оператора;
- **Голосовая первая линия** — транскрибация, аудит встреч, голосовые ассистенты;
- **Telegram-боты: поддержка и HR** — приём обращений, онбординг, обработка резюме;
- **Продажи и CRM** — AI-квалификация лидов на входе;
- **Анализ данных** — диалоговый data-ассистент с отчётами;
- **Качество AI** — автоматическая проверка промптов;
- **ML-глубина** — дообучение моделей под задачу (LoRA).

## Как пользоваться этой картой

- **Знаете свою бизнес-задачу** — найдите близкое направление выше; ассистент поможет подобрать кейс, если описать задачу текстом.
- **Ищете по технологии** (RAG, Telegram, голос, LoRA) — термины расшифрованы в [глоссарии](GLOSSARY.md), проекты по технологиям — в [матрице компетенций](COMPETENCIES.md).
- **Нужны доказательства реализации** — на каждой странице кейса есть ссылки на GitHub, демо и документацию.

*Официальный источник состава портфеля — реестр проектов платформы (администрируется владельцем); этот обзор синхронизируется с ним при изменениях состава.*
