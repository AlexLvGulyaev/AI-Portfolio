# Маршрут проверки демо — AI Portfolio

Рабочая инструкция ассистента портфеля. Если зритель спрашивает, что
проверить в демо, и не называет кейс, — не перечисляйте кейсы. Дайте
быстрый старт на флагманском веб-стенде (секция ниже) и скажите, что
на странице любого кейса получите маршрут именно по нему. Если кейс
назван — дайте его маршрут по документу DEMO_ROUTE его репозитория.

## Быстрый старт (без выбора кейса)

1. **Открыть** [AI Curator](https://curator.alex-n8n.site) →
   **выбрать** демо-роль (active_student / late_student / new_student) →
   **задать** вопрос об учебном материале → **проверить**, что под
   ответом стоят карточки источников: база знаний и задание из LMS.
2. **Продолжить** вопросы до лимита → **увидеть** честное ограничение
   safe demo mode: бейдж с квотой, rate limit и таймер сессии.

## Маршрут по конкретному кейсу

1. **Открыть** [витрину](https://ai.alex-n8n.site) → **выбрать** кейс →
   **открыть** страницу кейса.
2. **Спросить** ассистента на странице: «Я иду смотреть демо — что
   проверить?» → **получить** нумерованный маршрут «открыть → сделать →
   увидеть» по этому кейсу (источник — DEMO_ROUTE репозитория кейса).
3. **Пройти** маршрут по живому демо кейса → **увидеть** ключевой
   результат: у каждого кейса свой канал — веб-стенд или Telegram-бот.
4. **Сравнить** кейсы: спросить ассистента на витрине про кейс по
   имени («Расскажи про Review Flow») → **увидеть** суть, результаты
   и ссылки на живое демо.
