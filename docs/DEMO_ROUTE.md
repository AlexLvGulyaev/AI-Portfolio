# Маршрут проверки демо — AI Portfolio

Как быстро увидеть платформу в работе: ассистент портфеля сам даёт
маршрут проверки для любого кейса. Можно начать с витрины или сразу
с флагманского веб-стенда.

## Маршрут проверки

1. **Открыть** [витрину](https://ai.alex-n8n.site) → **выбрать** кейс →
   **открыть** страницу кейса → **спросить** ассистента на странице:
   «Я иду смотреть демо — что проверить?» → **получить** нумерованный
   маршрут «открыть → сделать → увидеть» именно по этому кейсу
   (источник — документ DEMO_ROUTE репозитория кейса).
2. **Пройти** маршрут по живому демо кейса → **увидеть** ключевой
   результат: у каждого кейса свой канал — веб-стенд или Telegram-бот.
3. **Быстрый старт без выбора**: [AI Curator](https://curator.alex-n8n.site)
   → выбрать демо-роль (active_student / late_student / new_student) →
   задать вопрос об учебном материале → **проверить**, что под ответом
   стоят карточки источников: база знаний и задание из LMS.
4. **Сравнить** два кейса: задать ассистенту на витрине вопрос с
   названием проекта («Расскажи про Review Flow») → **увидеть** суть,
   результаты и ссылки на живое демо.
