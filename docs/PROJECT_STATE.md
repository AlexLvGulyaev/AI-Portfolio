**2.1. Качество проектной документации и KB admission gate**

Зафиксированное ограничение (27.08.2026):

- Не у всех портфельных проектов документация доведена до стандартов APL.
- Подключение репозитория к GitHub Sync **не означает** индексацию всех найденных в нём Markdown-файлов.
- Загрузка в KB устаревшей, противоречивой, внутренней или фактически неточной документации недопустима: качество источников напрямую определяет достижение обязательной метрики корректности AI-ассистента **≥90%**.

Для каждого источника вводится **KB admission gate** — реализация уже утверждённого требования M6 (управление источниками и составом индексируемых материалов), а не новая архитектура:

1. Определить фактический репозиторий источника.
2. Проверить публичность, актуальность и непротиворечивость документов.
3. Определить разрешённый состав индексируемых материалов.
4. Исключить из индексации внутренние, устаревшие и неподтверждённые документы.
5. При отсутствии пригодного корпуса — сначала актуализировать минимальный канонический публичный документ проекта.
6. Только после допуска подключать источник и выполнять reindex.
7. После формирования чистого корпуса — запускать eval и настройку retrieval/prompt.

**Статус (28.08.2026):** кампания допуска завершена — все 12 репозиториев витрины допущены и синхронизированы; незавершённость документации отдельных проектов **не является блокировкой** уже завершённой кампании допуска. Она сохраняется как **известное ограничение качества источников**: при будущих допусках (включая собственный корпус AI Portfolio) применяется тот же механизм — admission gate с выборочным составом индексации и, при необходимости, актуализацией минимального канонического документа. Исправление документации всех портфельных проектов не входит в текущий проход.

**Готовность механизма:** backend admission gate готов полностью (миграция 014, PATCH `admission_status`/include/exclude, `admission-preview`, guard'ы sync/delete, тесты — коммит `f899f24`); **UI управления допуском реализован 28.08.2026 (§4.5а)** — Admission Console на `/content/sources`, миграция 015 (kb_admission_previews, kb_admission_events), consistent draft/effective-модель, stale-защита одобрения, аудит решений.
